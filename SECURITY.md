# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within ResearchMind AI, please help us keep the project secure.

- Do **not** open a public issue for security-sensitive bugs.
- Please report vulnerabilities directly to the project maintainers via email or private GitHub security advisories.
- Include detailed steps to reproduce the issue and any relevant system information.
- We will acknowledge receipt of your report and provide updates as the fix is developed and released.
